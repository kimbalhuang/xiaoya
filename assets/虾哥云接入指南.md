# 虾哥云（XiaoZhi 公共服）接入指南

> 完整流程：**获取设备注册码 → xiaozhi.me 添加设备 → 激活确认 → WebSocket 联通聊天**
> 适用：任何需要接入 `api.tenclass.net` 虾哥云公共服的项目（ESP32 / Flutter / Python / Web 均可）
> 整理时间：2026-07-31（已实测打通）

---

## 0. 架构总览

```
┌──────────── 你的设备/程序 ────────────┐        ┌──────── 虾哥云公共服 ────────┐
│                                      │  HTTP   │                             │
│  1. POST /xiaozhi/ota/               │ ──────► │  返回激活码(4位) + challenge │
│     (带 Device-Id / Client-Id 头)    │ ◄────── │  （已激活则返回 WS 配置）    │
│                                      │         │                             │
│  2. 用户去 xiaozhi.me 输入激活码     │         │                             │
│                                      │  HTTP   │                             │
│  3. POST /xiaozhi/ota/activate       │ ──────► │  HMAC 校验 → 200 激活成功   │
│     (HMAC-SHA256 签名, 轮询 202)     │ ◄────── │                             │
│                                      │         │                             │
│  4. WebSocket wss://.../xiaozhi/v1/  │ ──────► │  hello → 发文本/音频        │
│     (带真实设备身份头)               │ ◄────── │  LLM 回复 + TTS Opus 音频   │
└──────────────────────────────────────┘         └─────────────────────────────┘
```

**核心要点**：四个环节用的**设备身份必须一致**（device_id / client_id / serial_number / hmac_key），否则激活失败或连接被断开。

## 2. 设备身份生成（必须持久化）

虾哥云按「设备」认证，每个设备有 4 个身份参数，**生成一次永久使用**（建议存 JSON 文件）：

| 参数 | 生成规则 | 示例 |
|------|---------|------|
| `device_id` | MAC 风格 `xx:xx:xx:xx:xx:xx`（6 组两位十六进制） | `e1:13:24:44:bc:e8` |
| `client_id` | UUID v4 | `5642532c-dece-4454-bc2f-05e03aae3b90` |
| `serial_number` | `SN-{MD5(mac_clean)[:8].upper()}-{mac_clean}`，mac_clean=去冒号小写 | `SN-777587B7-e1132444bce8` |
| `hmac_key` | `sha256(device_id + "||" + client_id)` 的 hex | `70125d04...` |

Python 生成脚本：

```python
import uuid, hashlib, random, json

device_id = ":".join(f"{random.randint(0,255):02x}" for _ in range(6))
client_id = str(uuid.uuid4())
mac_clean = device_id.replace(":", "").lower()
serial_number = f"SN-{hashlib.md5(mac_clean.encode()).hexdigest()[:8].upper()}-{mac_clean}"
hmac_key = hashlib.sha256(f"{device_id}||{client_id}".encode()).hexdigest()

identity = {
    "device_id": device_id,
    "client_id": client_id,
    "serial_number": serial_number,
    "hmac_key": hmac_key,
}
with open("xiaozhi_device.json", "w", encoding="utf-8") as f:
    json.dump(identity, f, ensure_ascii=False, indent=2)
print("设备身份已保存:", device_id)
```

> ⚠️ **device_id 尽量不要随机重新生成**——换了设备身份就相当于换了一台新设备，需要重新注册。注册完成后把 JSON 存好，后面所有请求都用它。

## 3. 获取设备注册码（POST /ota/）

### 3.1 请求

```
POST https://api.tenclass.net/xiaozhi/ota/
```

**Headers**（必须）：

```
Device-Id: <device_id>
Client-Id: <client_id>
Content-Type: application/json
User-Agent: flutter/xiaozhi-flutter-1.0.0
Accept-Language: zh-CN
```

**Body**（JSON）：

```json
{
  "application": {
    "version": "1.0.0",
    "elf_sha256": "unknown"
  },
  "board": {
    "type": "flutter",
    "name": "xiaozhi-flutter",
    "ip": "",
    "mac": "<device_id>"
  }
}
```

### 3.2 响应（两种可能）

**情况 A：设备未注册** → 返回 `activation` 对象：

```json
{
  "server_time": {...},
  "websocket": {
    "url": "wss://api.tenclass.net/xiaozhi/v1/",
    "token": "test-token"
  },
  "activation": {
    "code": "430696",                 // ← 4 位注册码，去 xiaozhi.me 输入
    "message": "xiaozhi.me\n430696",
    "challenge": "12b11a85-0592-4344-8cf7-eab99b9089d1"   // ← 激活签名用
  }
}
```

**情况 B：设备已注册** → 响应里**没有** `activation` 字段，只有 `websocket`：

```json
{
  "websocket": {
    "url": "wss://api.tenclass.net/xiaozhi/v1/",
    "token": "test-token"
  }
}
```

判断逻辑：`if "activation" in resp: 需要注册 else: 已激活`

## 4. 添加设备（xiaozhi.me 网页操作）

1. 浏览器打开 **https://xiaozhi.me** → 注册/登录
2. 进入「控制台」
3. 找到「设备管理 / 添加设备」
4. 输入上一步拿到的 **4 位注册码**（如 `430696`）
5. 提交完成绑定

> 绑定后设备立即生效。若提示找不到设备码，确认第 3 步 POST 用的 device_id 与本次一致。

## 5. 激活确认（POST /ota/activate，轮询）

用户绑定后，用服务器返回的 `challenge` + 设备 `hmac_key` 生成签名，POST 确认。服务器在用户绑定完成前返回 **202**，绑定完成后返回 **200**，所以需要**轮询**（每 5 秒一次，最多 10 分钟）。

### 5.1 签名

```python
import hmac, hashlib
sig = hmac.new(
    identity["hmac_key"].encode(),      # key
    challenge.encode(),                 # 消息 = 服务器返回的 challenge
    hashlib.sha256
).hexdigest()
```

### 5.2 请求

```
POST https://api.tenclass.net/xiaozhi/ota/activate
```

**Headers**：

```
Activation-Version: 2
Device-Id: <device_id>
Client-Id: <client_id>
Content-Type: application/json
```

**Body**：

```json
{
  "Payload": {
    "algorithm": "hmac-sha256",
    "serial_number": "<serial_number>",
    "challenge": "<服务器返回的challenge>",
    "hmac": "<上面算出的签名>"
  }
}
```

### 5.3 响应

| HTTP | 含义 | 处理 |
|------|------|------|
| **200** | ✅ 激活成功（返回 `{"message":"Device activated","device_id":...}`） | 进入第 6 步 |
| **202** | ⏳ 用户还没在 xiaozhi.me 输入注册码 | 等 5 秒继续轮询 |
| 其他 | 错误 | 读 body 的 `error` 字段 |

## 6. 联通聊天（WebSocket）

激活成功后，用第 3 步返回（或重新 GET/POST /ota/ 得到）的 `websocket.url` 和 `websocket.token` 连接。

### 6.1 连接 Headers（关键！）

**必须用激活设备的真实身份**，缺一个或多个会被服务器在 hello 后直接断开（1005）：

```
Authorization: Bearer <token>          # 来自 /ota/ 响应的 websocket.token
Protocol-Version: 1
Client-Id: <device_id 对应的 client_id>   # 与激活时一致
Device-Id: <device_id>                    # 与激活时一致
Serial-Number: <serial_number>            # 与激活时一致（推荐带）
```

> ⚠️ 实测踩坑：不带上面对应关系、随便填 `chat-device-01` 这种，握手成功但发送 hello 后服务器直接 1005 断开。**四个身份必须与激活设备完全一致**。

### 6.2 消息流程

**① 发送 hello**（JSON）：

```json
{
  "session_id": "sess-<时间戳>",
  "type": "hello",
  "version": 1,
  "transport": "websocket",
  "audio_params": {
    "format": "opus",
    "sample_rate": 16000,
    "channels": 1,
    "frame_duration": 60
  }
}
```

**② 发送对话**（两种方式）：

- **文本**（直接跟 LLM 聊）：

```json
{
  "session_id": "sess-xxx",
  "type": "listen",
  "state": "detect",
  "text": "你好，测试一下对话"
}
```

- **音频**（说话，需要 Opus 编码麦克风 PCM → 二进制帧逐帧发送，16kHz/60ms/单声道）：

```
二进制帧（Opus 编码的音频数据，不加 JSON 头）
```

**③ 接收**（服务器→客户端）：

| 类型 | 内容 |
|------|------|
| 二进制帧 | Opus 编码的 TTS 音频（4 字节小端长度前缀 + Opus 数据） |
| `{"type":"hello",...}` | 握手确认 |
| `{"type":"stt","text":...}` | 语音识别结果（音频输入时） |
| `{"type":"llm","text":...,"emotion":...}` | LLM 回复文本（**带 emotion 情绪标签**，可驱动数字人表情） |
| `{"type":"tts","state":"start"}` | TTS 开始 |
| `{"type":"tts","state":"sentence_start","text":...}` | 当前正在播报的句子 |
| `{"type":"tts","state":"sentence_end","text":...}` | 句子播报结束 |
| `{"type":"tts","state":"stop"}` | TTS 结束（音频帧收完） |

### 6.3 实测效果

```
➡️ 发送: 「你好，测试一下对话」
⬅️ {"type":"llm","text":"测试对话没问题，我这边听得很清楚喔～",...}
⬅️ {"type":"tts","state":"sentence_start","text":"测试对话没问题..."}
⬅️ [106 帧 Opus 音频]
⬅️ {"type":"tts","state":"stop"}
```

## 8. 常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| POST /ota/ 只返回 `{"status":"ok"}` | 用了 GET 或没带 JSON body | 必须 POST + JSON body + Device-Id/Client-Id 头 |
| /ota/activate 一直 202 | 用户还没在 xiaozhi.me 输入注册码 | 等用户绑定，轮询即可 |
| WS 握手成功但 hello 后 1005 断开 | 连接头设备身份与激活设备不一致 | 用激活时的 device_id/client_id/serial_number |
| hello 无响应 | session_id 缺失或格式不对 | 加上 `session_id` + 完整 `audio_params` |
| websockets 17 报错 | 异步/同步 API 混用 | `from websockets.sync.client import connect`（同步） |
| 收到音频但没文本 | 音频输入时 stt/llm 消息在 TTS 前 | 先处理 `stt` → `llm` → `tts` 顺序 |

## 9. 其他项目接入最小模板

```python
# 独立于任何框架的最小接入（Python）
import json, time, hmac, hashlib, requests

def get_activation_code(identity):
    """Step 1: 获取注册码"""
    r = requests.post("https://api.tenclass.net/xiaozhi/ota/",
        data=json.dumps({
            "application": {"version": "1.0.0", "elf_sha256": "unknown"},
            "board": {"type": "flutter", "name": "xiaozhi-flutter", "ip": "", "mac": identity["device_id"]},
        }),
        headers={
            "Device-Id": identity["device_id"],
            "Client-Id": identity["client_id"],
            "Content-Type": "application/json",
            "User-Agent": "flutter/xiaozhi-flutter-1.0.0",
        }, timeout=15)
    return r.json()   # 含 activation.code 或 websocket

def confirm_activation(identity, challenge):
    """Step 2: 轮询激活确认"""
    sig = hmac.new(identity["hmac_key"].encode(), challenge.encode(), hashlib.sha256).hexdigest()
    for _ in range(120):
        r = requests.post("https://api.tenclass.net/xiaozhi/ota/activate",
            data=json.dumps({"Payload": {
                "algorithm": "hmac-sha256",
                "serial_number": identity["serial_number"],
                "challenge": challenge,
                "hmac": sig,
            }}),
            headers={
                "Activation-Version": "2",
                "Device-Id": identity["device_id"],
                "Client-Id": identity["client_id"],
                "Content-Type": "application/json",
            }, timeout=10)
        if r.status_code == 200:
            return True
        time.sleep(5)
    return False

def connect_ws(identity, ws_url, token):
    """Step 3: WebSocket 聊天"""
    from websockets.sync.client import connect
    headers = {
        "Authorization": f"Bearer {token}",
        "Protocol-Version": "1",
        "Client-Id": identity["client_id"],
        "Device-Id": identity["device_id"],
        "Serial-Number": identity["serial_number"],
    }
    with connect(ws_url, additional_headers=headers, max_size=10*1024*1024) as ws:
        sess = f"sess-{int(time.time())}"
        ws.send(json.dumps({
            "session_id": sess, "type": "hello", "version": 1,
            "transport": "websocket",
            "audio_params": {"format": "opus", "sample_rate": 16000, "channels": 1, "frame_duration": 60},
        }))
        ws.send(json.dumps({"session_id": sess, "type": "listen", "state": "detect", "text": "你好"}))
        # 收消息...
        while True:
            msg = ws.recv()
            print(msg[:200] if isinstance(msg, str) else f"[音频] {len(msg)} bytes")
```

## 附：关键端点汇总

| 端点 | 方法 | 用途 |
|------|------|------|
| `https://api.tenclass.net/xiaozhi/ota/` | POST | 获取注册码 / 查询激活状态 |
| `https://api.tenclass.net/xiaozhi/ota/activate` | POST | 激活确认（HMAC 签名） |
| `wss://api.tenclass.net/xiaozhi/v1/` | WS | 语音/文本聊天 |
| `https://xiaozhi.me` | 网页 | 账号注册 + 设备绑定 |

> 注：OTA 端点是 HTTP（不是 WS）；语音/文本聊天用 `/v1/` WebSocket。两者不要混用。
