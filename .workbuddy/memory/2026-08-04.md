## 修复：本地 FlashHead 启用后回复语音重复播放
- 根因：本地 FlashHead 在线时 mode=live，浏览器经 audioSync.push 缓冲小智 TTS 帧（不播），改由数字人视频音轨输出。然视频 onEnded 触发 `audioSync.setVideoActive(false)` 会把缓冲 TTS **补播**——与视频音轨为同一段语音，造成"重复播放"。
- 修复（xiaozhi-web/，未改 UI/基本逻辑）：
  1. `src/lib/audioSync.ts`：新增 `endVideo()`——视频（带声）正常播完时丢弃缓冲 TTS 并置 videoActive=false（不重播），仅在视频被静音/失败降级时才走 setVideoActive(false) 补播 TTS 兜底。
  2. `src/components/Avatar.tsx`：`onEnded` 改为按视频是否真正带声分支——`videoRef.muted` 为真（静音降级）→ setVideoActive(false) 补播 TTS；否则 → endVideo() 丢弃缓冲，杜绝重复。
- 验证：`npm run build` 成功（无新增错误）。
